Multi-Armed Bandit: Where to pull next?

  • There are several arms, each with an unknown reward probability.
  • At each round, the agent chooses one arm and gets a reward.
  • The goal is to learn which arm is best while collecting as much reward as possible.
  • This creates the classic trade-off between exploration and exploitation.

Core ideas

Action selection

At each round, the agent chooses one slot machine or arm. Each arm has an unknown reward probability.

Exploration

Try unfamiliar arms to estimate their reward distribution without prematurely committing to one choice.

Exploitation

Use the information gathered so far to keep selecting the arm that currently appears most rewarding.

Common bandit strategies

Greedy Strategy

Pick the current best-known arm to maximize short-term reward after sufficient learning.

Epsilon-Greedy

With probability ε, choose a random arm; otherwise choose the arm with the highest empirical mean.

Upper Confidence Bound

Choose the arm with the largest optimistic estimate: mean + exploration bonus based on uncertainty.

Action value definitions
  • True value: The true value of an action a is the mean reward received when action a is selected.
  • Estimated value: If action a has been selected N_t(a) times by time t, yielding rewards R_1, R_2, ..., R_{N_t(a)}, then the estimated value is Q_t(a) = (R_1 + R_2 + ... + R_{N_t(a)}) / N_t(a).
  • If N_t(a) = 0, then we define Q_t(a) as a default value, such as Q_t(a) = 0.
  • As N_t(a) → ∞, by the law of large numbers, Q_t(a) converges to the true value of the action.

# Sample from a Bernoulli bandit
import random

def pull_arm(probability):
    return 1 if random.random() < probability else 0

probabilities = [0.10, 0.25, 0.60, 0.80]
rewards = []
for _ in range(1000):
    arm = random.randrange(len(probabilities))
    rewards.append(pull_arm(probabilities[arm]))

print("Average reward:", sum(rewards) / len(rewards))
import random, math

def epsilon_greedy(arms, epsilon, num_rounds):
    counts = [0] * len(arms)
    values = [0.0] * len(arms)
    total_reward = 0

    for _ in range(num_rounds):
        if random.random() < epsilon:
            arm = random.randrange(len(arms))
        else:
            arm = max(range(len(arms)), key=lambda i: values[i])

        reward = 1 if random.random() < arms[arm] else 0
        counts[arm] += 1
        values[arm] += (reward - values[arm]) / counts[arm]
        total_reward += reward

    return total_reward

arms = [0.10, 0.20, 0.70, 0.55]
print(epsilon_greedy(arms, 0.10, 5000))
import random, math

def ucb(arms, num_rounds):
    counts = [0] * len(arms)
    rewards = [0.0] * len(arms)
    total_reward = 0

    for t in range(1, num_rounds + 1):
        score = []
        for i in range(len(arms)):
            if counts[i] == 0:
                score.append((float('inf'), i))
            else:
                bonus = math.sqrt((2 * math.log(t)) / counts[i])
                score.append((rewards[i] + bonus, i))

        arm = max(score, key=lambda x: x[0])[1]
        reward = 1 if random.random() < arms[arm] else 0
        counts[arm] += 1
        rewards[arm] += (reward - rewards[arm]) / counts[arm]
        total_reward += reward

    return total_reward

arms = [0.12, 0.45, 0.80, 0.30]
print(ucb(arms, 5000))

Lab objective

Simulate a multi-armed bandit problem and compare how different algorithms balance exploration and exploitation. Your goal is to understand why a simple greedy policy can get stuck on a mediocre arm, while uncertainty-aware methods can discover better arms more efficiently.

1
Implement a bandit environment

Write a Bernoulli reward function where each arm has a different success probability. The system should return 1 for a win and 0 for a loss.

Expected logic: sample a random number and compare it to the arm's probability.
2
Compare ε-greedy and UCB

Run the same bandit environment under two strategies: ε-greedy and UCB. Record cumulative reward after 2000 rounds and explain which one learns faster.

Hint: UCB usually performs better in early rounds because it explores uncertain arms more intelligently.
